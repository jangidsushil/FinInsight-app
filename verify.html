Check the file you downloaded

Its SHA-256 checksum must match the one above, letter for letter. On a computer:

# Windows (PowerShell)
Get-FileHash FinInsight.apk -Algorithm SHA256

# macOS or Linux
shasum -a 256 FinInsight.apk

To check the signing certificate, use apksigner from the Android SDK, or any APK-inspector app on the phone:

apksigner verify --print-certs FinInsight.apk

# it should print
Signer #1 certificate SHA-256 digest:
d33ebf52e002e935efff8e24e0cc5d5242bb49d84f1e5764ff95fc27613cab64

Updates can't be swapped

  • Android itself installs an update only when it is signed with the same certificate as the app already on your phone. Once you have the real FinInsight, a tampered copy can't replace it — Android says "App not installed".
  • The in-app updater downloads only from this website over HTTPS, then checks the file's SHA-256 and its signing certificate before it offers to install. A file that doesn't match is deleted.

Nothing leaves your phone — and the build checks it

Every build of FinInsight runs a privacy check that fails the build if the app's own code opens any network connection except the update check to this website. The only other connections are made by the ad SDK, to load ads in the free version, and by Google Play, when you buy Pro. Neither is given your messages or your books, and the advertising ID is removed from the app.

You can see it yourself: switch off mobile data and Wi-Fi. Everything works — reading messages, reports, Scam Shield, the lock — except ads and the update check.
