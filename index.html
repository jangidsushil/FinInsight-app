Install in a minute

FinInsight is installed straight from this page rather than the Play Store, so Android asks you to allow it once.

  1. Download. Tap Download for Android on your phone (Chrome works well).
  2. Open the file. When the download finishes, tap Open — or find FinInsight.apk in Files › Downloads.
  3. Allow the install. If asked, allow Install unknown apps for your browser or Files app, then go back.
  4. Install. Tap Install. If Android says "This type of file can harm your device", tap Install anyway — this appears for every app installed outside the Play Store.
  5. Set up. Open FinInsight and follow the short set-up. To update later, download from the same link and tap Update — your books stay as they are.

Common problems and fixes

"App not installed" or "Package conflicts with an existing package"

You have a copy signed differently (for example an old test build). Make a backup (☰ › Settings › Backup), uninstall the old FinInsight, then install again and restore.

"App not installed as package appears to be invalid"

The download was cut short. Delete FinInsight.apk from Downloads and download it again on a stable connection.

"Blocked by Play Protect" or "Harmful app blocked"

You're installing the automatic-mode file directly. Install the standard FinInsight.apk first, then switch from inside the app (☰ › Automatic mode) — it explains how to pause Play Protect for that one install and reminds you to turn it back on.

Android keeps asking to allow "Install unknown apps"

Android asks once for each app that installs files (Chrome, Files, WhatsApp…). Allow it for the app you're installing from.

Nothing shows after set-up

The standard edition can't read SMS by itself. Make a backup with "SMS Backup & Restore" (keep only Messages switched on) and choose that file in FinInsight — or share a bank message to FinInsight from your SMS app.

A transaction is missing or wrong

Some banks send unusual formats. Open the transaction (or ☰ › To confirm) and correct it once — FinInsight remembers. To check an account completely, import its bank statement (☰ › Bank statements).

The same account shows twice

Banks sometimes mask numbers differently. Open one in ☰ › Accounts & cards and choose Same as another account.

"No ad available right now"

Ads sometimes run out for a moment, especially on slow connections. Try again in a minute; you can watch up to 10 a day.

Notifications don't arrive

Allow notifications for FinInsight in Android settings, and set its battery use to Unrestricted (Settings › Apps › FinInsight › Battery).

Someone nearby can see my amounts

Tap the eye at the top of the screen to hide every amount. Set a PIN or fingerprint lock in ☰ › Settings.

Still stuck? In the app: ☰ › Report a problem — or email fininsight@yahoo.com.
